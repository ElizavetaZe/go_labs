# Лабораторная работа №7
## Описание задания
В данной лабораторной работе необходимо реализовать программы для работы с сетью:
1. Создание TCP-сервера, который принимает сообщения клиента и отправляет подтверждение.
2. Реализация TCP-клиента, который отправляет сообщение, введённое пользователем.
3. Асинхронная обработка клиентов с помощью горутин и graceful shutdown сервера.
4. Создание HTTP-сервера с обработкой GET и POST запросов.
5. Добавление маршрутизации и middleware для логирования запросов.
6. Реализация чата на веб-сокетах.
## Структура проекта
```
task1/main.go  - TCP-сервер
task2/main.go  - TCP-клиент
task3/main.go  - TCP-сервер с горутинами и graceful shutdown
task4/main.go  - HTTP-сервер
task5/main.go  - HTTP-сервер с маршрутизацией и middleware
task6/main.go  - чат на веб-сокетах
README.md
```
## Инструкция по запуску
1. Открыть терминал в папке 'lab7'.
2. Один раз выполнить команды `go mod init lab7` и `go mod tidy` (вторая скачивает библиотеку gorilla/websocket для задания 6).
3. Запустить нужное задание командой `go run ./task1` (или `./task2`, `./task3` и т.д.).

Все серверы используют порт 8080, поэтому запускать их нужно по одному. Для заданий 1-3 клиент (`go run ./task2`) запускается в отдельном терминале.

## Примеры работы программы
## Задание 1: Создание TCP-сервера
Сервер слушает порт 8080, принимает клиента, выводит полученное сообщение и отправляет подтверждение. Клиенты обслуживаются по очереди.
```
Сервер запущен на порту 8080
Получено: Привет, сервер
```
## Задание 2: Реализация TCP-клиента
Клиент подключается к серверу, отправляет введённое сообщение, получает ответ и завершает работу.
```
Введите сообщение:
Привет, сервер
Отправлено: Привет, сервер
Ответ сервера: Сообщение получено: Привет, сервер
```
## Задание 3: Асинхронная обработка клиентов и graceful shutdown
Каждый клиент обрабатывается в отдельной горутине, поэтому сервер работает с несколькими клиентами одновременно. При нажатии Ctrl+C сервер перестаёт принимать новых клиентов (закрывает listener), с помощью `sync.WaitGroup` дожидается завершения уже подключённых и только потом останавливается. Для демонстрации в обработчик добавлена задержка 3 секунды.
```
Сервер запущен на порту 8080. Для остановки нажмите Ctrl+C
Получено: Привет, сервер
^C
Получен сигнал остановки, ждём активные соединения...
Сервер остановлен
```
## Задание 4: Создание HTTP-сервера
Сервер обрабатывает два пути: `GET /hello` возвращает приветствие, `POST /data` принимает JSON, преобразует его в структуру и выводит в консоль. При неверном методе возвращается ошибка 405.
```
curl http://localhost:8080/hello
Здравствуйте, клиент

curl -X POST http://localhost:8080/data -d '{"Name":"Анна","Age":20}'
{"status":"ok"}
```
Вывод сервера:
```
Получено: {Name:Анна Age:20}
```
## Задание 5: Маршрутизация и middleware
Маршруты регистрируются в `http.ServeMux`. Middleware `logging` оборачивает весь маршрутизатор: запоминает время, вызывает обработчик и выводит метод, URL и время выполнения каждого запроса.
```
Метод: GET URL: /hello Время: 25.3µs
Получено: {Name:Анна Age:20}
Метод: POST URL: /data Время: 142.1µs
```
## Задание 6: Веб-сокеты (чат)
Сервер принимает веб-сокет-соединения на пути `/ws`, а по адресу `/` отдаёт страницу чата. Для каждого клиента работает своя горутина, которая читает его сообщения и рассылает их всем подключённым клиентам. Список клиентов защищён мьютексом. Чтобы проверить чат, нужно открыть `http://localhost:8080` в двух вкладках браузера и отправить сообщение в одной из них: оно появится в обеих.
```
Доброе утро!
Привет
```
