# Лабораторная работа №1
## Описание задания
В данной лабораторной работе необходимо реализовать программу, которая выполняет следующие задачи:
1. Вывод текущего времени и даты.
2. Создание переменных различных типов, таких как 'int', 'float64', 'string', 'bool'
3. Использование краткой формы  объявления переменных ':=' для создания и вывода переменных.
4. Выполнение арифметических операций (сложение, вычитание, умножение, деление, остаток) с двумя целыми числами.
5. Вычисление суммы и разности двух чисел с плавающей запятой с использованием функции.
6. Вычисление среднего значения трёх целых чисел.
## Структура проекта
main.go
README.md
## Инструкция по запуску
1. Открыть терминал в папке 'lab1'
2. Выполнить команду go run main.go
