# Лабораторная работа №5
## Описание задания
В данной лабораторной работе необходимо реализовать программу, которая выполняет следующие задачи:
1. Создание структуры Person с полями name и age. Реализация метода для вывода информации о человеке.
2. Реализация метода birthday для структуры Person, который увеличивает возраст на 1 год.
3. Создание структуры Circle с полем radius и метода для вычисления площади круга.
4. Создание интерфейса Shape с методом Area(). Реализация этого интерфейса для структур Rectangle и Circle.
5. Реализация функции, которая принимает срез интерфейсов Shape и выводит площадь каждого объекта.
6. Создание интерфейса Stringer и его реализация для структуры Book, которая хранит информацию о книге.
