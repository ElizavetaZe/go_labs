# Лабораторная работа №3
## Описание задания
В данной лабораторной работе необходимо реализовать программу, которая выполняет следующие задачи:
1. Создание собственного пакета 'mathutils' с функцией для вычисления факториала числа.
2. Использование пакета 'mathutils' для вычисления факториала числа, введённого пользователем.
3. Создание собственного пакета 'stringutils' с функцией для переворота строки и использование его в основной программе.
4. Создание массива из 5 целых чисел, заполнение его значениями и вывод на экран.
5. Создание среза из массива и выполнение операций добавления и удаления элементов.
6. Создание среза из строк и нахождение самой длинной строки.
## Структура проекта
main.go
README.md
mathutils/factorial.go
stringutils/reserveStr.go
## Инструкция по запуску
1. Открыть терминал в папке 'lab3'
2. Выполнить команду go run main.go
## Примеры работы программы
## Задание 1-2: Вычисление факториала
Программа запрашивает ввод целого числа и вычисляет его факториал с использованием пакета mathutils.
Введите число: 
5
Факториал введеннного числа 120
## Задание 3: Переворот строки
Программа запрашивает ввод строки и выводит её в перевёрнутом виде с использованием пакета stringutils.
Введите строку: 
fghj
Перевернутая строка:  jhgf
## Задание 4: Работа с массивом
Программа создаёт массив из 5 случайных чисел и выводит его на экран.
Массив: 
[93 32 80 67 17]
## Задание 5: Работа со срезом массива
Программа демонстрирует создание среза из массива, добавление и удаление элементов.
Срез массива:  [15 10 7]
Массив после добавления элементов:  [15 10 7 50 0]
Массив после удаления элемента:  [15 10 50 0]
## Задание 6: Поиск самой длинной строки
Программа создаёт срез из строк и находит самую длинную строку.
Самая длинная строка:  abracadabra  количество символов:  11
