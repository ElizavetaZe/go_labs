# Документация API: управление пользователями

## Общие сведения
- Базовый адрес: `http://localhost:8080`
- Формат запросов и ответов: JSON
- Данные хранятся в базе PostgreSQL
- Запуск: `go run ./lab8` (PostgreSQL должен быть запущен)

## Модель пользователя
| Поле | Тип | Описание |
|---|---|---|
| `id` | число | Уникальный номер. Выдаётся сервером, в запросах передавать не нужно |
| `name` | строка | Имя. Не должно быть пустым или состоять только из пробелов |
| `age` | число | Возраст: целое число от 1 до 120 |

Пример: `{"id": 1, "name": "Anna", "age": 20}`

## Список маршрутов
| Метод | Адрес | Описание | Успешный ответ |
|---|---|---|---|
| GET | `/users` | Список пользователей (с фильтрацией и пагинацией) | 200 |
| GET | `/users/{id}` | Информация о пользователе | 200 |
| POST | `/users` | Добавление пользователя | 201 |
| PUT | `/users/{id}` | Обновление пользователя | 200 |
| DELETE | `/users/{id}` | Удаление пользователя | 204 |

---

## GET /users
Возвращает список пользователей, отсортированный по `id`.

**Параметры запроса** (все необязательные, можно сочетать):

| Параметр | Тип | Описание | По умолчанию |
|---|---|---|---|
| `name` | строка | Поиск по части имени, регистр не важен | без фильтра |
| `age` | число | Только пользователи этого возраста | без фильтра |
| `page` | число | Номер страницы, от 1 | 1 |
| `limit` | число | Количество записей на странице, от 1 до 100 | 10 |

**Пример запроса:**
```
curl "http://localhost:8080/users?name=An&age=25&page=1&limit=5"
```

**Ответ 200:**
```json
[
  {"id": 2, "name": "Anton", "age": 25}
]
```
Если подходящих пользователей нет, возвращается пустой список `[]`.

**Ошибки:** 400, если `age`, `page` или `limit` не являются числом, `page` меньше 1 или `limit` вне диапазона от 1 до 100.

---

## GET /users/{id}
Возвращает одного пользователя.

**Параметр пути:** `id` — номер пользователя (число).

**Пример запроса:**
```
curl http://localhost:8080/users/1
```

**Ответ 200:**
```json
{"id": 1, "name": "Anna", "age": 20}
```

**Ошибки:** 400, если `id` не число; 404, если пользователя с таким `id` нет.

---

## POST /users
Добавляет нового пользователя. `id` назначается автоматически.

**Тело запроса (JSON), оба поля обязательны:**
```json
{"name": "Anna", "age": 20}
```

**Пример запроса:**
```
curl -X POST http://localhost:8080/users \
  -H "Content-Type: application/json" \
  -d '{"name":"Anna","age":20}'
```

**Ответ 201:**
```json
{"id": 1, "name": "Anna", "age": 20}
```

**Ошибки:** 400, если тело не является корректным JSON, имя пустое или возраст вне диапазона от 1 до 120. Пример ответа на `{"name":"Anna","age":200}`:
```json
{"error": "Возраст должен быть от 1 до 120"}
```

---

## PUT /users/{id}
Обновляет данные пользователя. Заменяет оба поля, поэтому они оба обязательны. Поле `id` в теле запроса игнорируется, используется `id` из адреса.

**Параметр пути:** `id` — номер пользователя (число).

**Тело запроса (JSON):**
```json
{"name": "Anna", "age": 21}
```

**Пример запроса:**
```
curl -X PUT http://localhost:8080/users/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"Anna","age":21}'
```

**Ответ 200:**
```json
{"id": 1, "name": "Anna", "age": 21}
```

**Ошибки:** 400, если `id` не число или данные неверны (те же правила, что в POST); 404, если пользователя нет.

---

## DELETE /users/{id}
Удаляет пользователя.

**Параметр пути:** `id` — номер пользователя (число).

**Пример запроса:**
```
curl -X DELETE http://localhost:8080/users/1
```

**Ответ 204:** успешно, тело ответа пустое.

**Ошибки:** 400, если `id` не число; 404, если пользователя нет.

---

## Коды ответов и ошибки
Ошибки возвращаются в формате `{"error": "описание"}`.

| Код | Сообщение | Когда возникает |
|---|---|---|
| 400 | Неверный JSON | тело запроса не является JSON или поле имеет неверный тип (например, `age` строкой) |
| 400 | Имя не может быть пустым | `name` пустое, не указано или состоит из пробелов |
| 400 | Возраст должен быть от 1 до 120 | `age` вне диапазона или не указан |
| 400 | Неверный id | `id` в адресе не число |
| 400 | Неверный параметр `age`/`page`/`limit` | значение не число или отрицательное |
| 400 | page должен быть от 1, limit от 1 до 100 | `page` или `limit` вне допустимого диапазона |
| 404 | Пользователь не найден | пользователя с таким `id` нет |
| 500 | Внутренняя ошибка сервера | ошибка на стороне сервера (например, недоступна база данных) |

Для несуществующих адресов сервер возвращает 404, а для неподдерживаемых методов 405 (обычным текстом, не JSON).
