# Лабораторная работа №4
## Описание задания
В данной лабораторной работе необходимо реализовать программу, которая выполняет следующие задачи:
1. Создание карты (map) с именами людей и их возрастами, добавление нового человека и вывод всех записей.
2. Реализация функции, которая принимает карту и возвращает средний возраст всех людей в карте.
3. Удаление записи из карты по заданному имени.
4. Чтение строки с ввода и вывод её в верхнем регистре.
5. Чтение нескольких чисел, введённых пользователем, и вывод их суммы.
6. Чтение массива целых чисел и вывод их в обратном порядке.
## Структура проекта
main.go
README.md
## Инструкция по запуску
1. Открыть терминал в папке 'lab4'
2. Выполнить команду go run main.go
## Примеры работы программы
## Задание 1: Создание карты с именами и возрастами
Программа создаёт карту с тремя записями и выводит их на экран.
map[Alice:31 Jane:18 Mike:52]
## Задание 2: Средний возраст
Программа вычисляет средний возраст всех людей в карте.
Средний возраст людей из карты: 33.67
## Задание 3: Удаление записи
Программа удаляет запись по имени "Alice" и выводит обновлённую карту.
Карта после удаления:  map[Jane:18 Mike:52]
## Задание 4: Преобразование строки в верхний регистр
Программа запрашивает ввод строки и выводит её в верхнем регистре.
Введите строку: 
hbj
Строка в верхнем регистре:  HBJ
## Задание 5: Сумма введенных чисел
Программа запрашивает количество чисел, затем сами числа и выводит их сумму.
Введите количество чисел, которое хотите ввести: 
3
Введите числа: 
15
10
5
Сумма введеных чисел:  30
## Задание 6: Вывод массива в обратном порядке
Программа запрашивает размер массива, его элементы и выводит их в обратном порядке.
Введите размер массива: 
4
Введите элементы массива: 
0
5
-25
16
Исходный массив:  [0 5 -25 16]
Перевернутый массив:  [16 -25 5 0]
